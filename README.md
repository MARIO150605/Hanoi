# JUEGO DE LAS TORRES DE HANOI

Proyecto desarrollado en Python que implementa el clásico problema de las Torres de Hanoi, permitiendo jugar de forma manual o visualizar su resolucion mediante un modo automatico.

## Descripción
Las Torres de Hanoi son un rompecabezas matemático que consiste en mover una serie de discos desde una torre de origen hasta una torre de destino utilizando una torre auxiliar, siguiendo estas reglas:

1. Solo se puede mover un disco a la vez.
2. Solo se puede mover el disco superior de una torre.
3. Nunca se puede colocar un disco grande sobre uno más pequeño.

## Alcance 
Los discos se representarán mediante números enteros, donde el número más grande representa el disco de mayor tamaño y el número más pequeño representa el disco de menor tamaño.  

En este proyecto no se utilizará una representación gráfica; toda la interacción se realizará mediante texto en la terminal.

## Ejecucion

python hanoi.py
